# **App Name**: CoursePilot

## Core Features:

- Course Information Retrieval: Fetch course details (description, schedule, instructor) from university websites based on user queries using a web scraping tool.
- Personalized Course Recommendations: AI-powered recommendations based on user-specified interests, skill level, and academic goals.
- User Profile Creation: Allow users to create profiles, specifying their interests, current courses, and academic goals to improve recommendation accuracy.
- Course Search and Filtering: Enable users to search for courses using keywords, and filter results based on various criteria such as department, level, and time slot.
- Course Comparison: Allow users to compare multiple courses side-by-side based on syllabus, difficulty, workload, and ratings.
- Rate courses: Let users rate and review courses that they've taken

## Style Guidelines:

- Primary color: Calm blue (#64B5F6) to inspire confidence and learning.
- Background color: Light blue-gray (#F0F4F7), very desaturated and bright, for a clean, focused feel.
- Accent color: Analogous turquoise (#4DD0E1) to draw attention to important UI elements.
- Body: 'PT Sans', a sans-serif font to improve readability.
- Headings: 'Space Grotesk', a modern sans-serif font to improve readability, bolder and with wider characters for a techy, scientific vibe.
- Use minimalist, clear icons to represent different course categories and functionalities.
- Maintain a clean, structured layout with ample whitespace to avoid overwhelming the user with information.
